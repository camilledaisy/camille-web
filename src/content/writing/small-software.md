Most software wants to grow. More users, more features, more *engagement*. I've been thinking about the opposite: software that is done.

A handmade mug doesn't get updates. It does one thing, and it gets better with use because *you* change around it.

## Some small software I love

- a text file called `ideas.txt` that I've kept since 2015
- a calendar app that only shows the next seven days
- a friend's website that tells you what the weather is like in her garden
